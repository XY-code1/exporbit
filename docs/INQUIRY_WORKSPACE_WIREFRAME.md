# TradePilot Inquiry Workspace 低保真页面布局

> 阶段：桌面端低保真 UI 设计  
> 目标：验证层级、任务流和信息密度，不定义视觉品牌或技术实现。

## 1. 布局方案

采用三工作区，建议基准画布 1440px：左栏约 280px，中间为弹性主区，右栏约 320px。尺寸仅用于低保真比例，不是开发标注。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ TradePilot       当前询盘：Nordlicht GmbH / Smart Earbuds     [状态] [⋯] │
├──────────────┬──────────────────────────────────────┬────────────────────────┤
│ 左：导航     │ 中：Inquiry Workspace               │ 右：Action Panel       │
│ [+ 新建询盘] │ [原始询盘] [Snapshot] [匹配] ...   │ 下一步                │
│ [搜索……]     │                                      │ □ 核实 CE 适用型号     │
│ [状态][7天]  │ BUSINESS SNAPSHOT                    │ □ 确认 MOQ             │
│              │ 客户需求 / 数量 / 国家              │                        │
│ ● 当前询盘   │ 产品候选 / 关键缺口 / 来源状态      │ 待确认事项            │
│ ○ 询盘 B     │                                      │ 2 项                   │
│ ○ 询盘 C     │ ─────────────────────────────────── │                        │
│              │ 当前任务内容                         │ [生成商务回复]         │
│ 最近处理     │ （按用户选择仅展开一个工作区块）     │                        │
└──────────────┴──────────────────────────────────────┴────────────────────────┘
```

### 左侧：Inquiry Navigation
- 新建询盘为固定主入口。
- 搜索、状态和时间筛选集中在列表上方。
- 列表项只显示客户/主题、更新时间、六种状态和待复核标记。
- “最近处理”默认最近 7 天，可切换时间范围。

### 中间：Inquiry Workspace
- 顶部保持当前询盘身份与二级导航。
- 默认展示 Business Snapshot，而非完整原文或全部研究结果。
- 原始询盘、产品匹配、客户调查、知识研究、证据和业务分析通过页内导航切换；同时只突出当前任务。
- Level 3 证据从对应字段打开覆盖式抽屉，关闭后回到触发位置。

### 右侧：Action Panel
- 固定呈现一个“下一步”主行动，下面列待确认事项和最多数条关键行动。
- 操作与中间内容联动；点击行动让中间区滚动/切换到对应上下文。
- 商务回复入口在条件满足时成为主 CTA；不在右侧内嵌完整编辑器。

## 2. 页面层级

1. **全局层：** 产品身份、当前询盘、状态、更多操作。
2. **任务层：** 左侧选择对象，中间执行当前任务，右侧提供下一步。
3. **情报层：** Snapshot → Business Intelligence → Research & Evidence。
4. **反馈层：** 局部加载、错误、保存、待复核，不用全屏遮罩替代业务内容。

## 3. 关键页面草图

### W-01 无询盘
```text
左栏：空列表                    中间：首次使用引导              右栏：隐藏
[+ 新建询盘]                   “导入第一封海外询盘”
                               支持文本 / PDF / 图片 / EML
                               [新建询盘]
```

### W-02 导入询盘
```text
┌ 导入询盘 ──────────────────────────────────────────────┐
│ [粘贴文本] [PDF] [图片] [EML]                          │
│ ┌ 文本/拖放区域 ┐   ┌ 文件队列：进度 / 失败 / 重试 ┐ │
│ └───────────────┘   └───────────────────────────────┘ │
│ 疑似重复：查看 2 条关联记录（不自动合并）              │
│                                    [取消] [创建并分析]  │
└────────────────────────────────────────────────────────┘
```

### W-03 Business Snapshot
```text
需求摘要 [CONFIRMED/INFERRED]        目标国家：Germany
数量：1,000 units                    产品匹配：2 个候选
────────────────────────────────────────────────────────
关键缺口：认证适用型号、目标交期
下一步：先核实 CE 适用范围                         [查看匹配]
```
只把客户背景、知乎研究、海外资料显示为一行摘要与“查看”，不铺开全文。

### W-04 产品匹配
```text
需求项：Wireless ANC Earbuds                   [+ 添加产品]
维度       Candidate A       Candidate B
类型       MATCH             MATCH
规格       MATCH             MISMATCH
MOQ        UNKNOWN           MATCH
OEM/ODM    MATCH             UNKNOWN
交付       UNKNOWN           MATCH
认证       UNKNOWN           UNKNOWN
[展开依据] [人工修正]                    [确认主推/备选]
```
不显示综合高分；用“已核实项/未知项”帮助判断。当前询盘的资料缺口在表下提示。

### W-05 知识与证据
```text
业务问题：[德国客户是否需要指定 CE 证书覆盖型号？]
[知乎社区] [海外公开] [企业资料]
来源 A  社区经验       [关联证据]
来源 B  官方/公开资料  [关联证据]
观点不同：人工对照                                  [查看]
证据 → 洞察 → 建议行动                              [展开链路]
```
自动冲突识别不作为首版状态或标签。

### W-06 Communication Studio
```text
目标 [澄清需求] 语言 [English] 语气 [Formal Business]
采用内容：☑ 确认数量  ☑ 询问认证  ☐ 内部风险
┌ 编辑器：人工可改，不自动覆盖 ────────────────────────┐
└──────────────────────────────────────────────────────┘
[历史版本]                       [保存版本] [最终确认]
```
最终确认后显示“撤销确认”；撤销与再次确认写入操作记录。

## 4. 响应式降级

- 1024px：左栏与 Action Panel 变为可打开抽屉，中间仍保留 Snapshot 优先。
- 390px：单列；列表与详情分层；右侧行动变为底部固定入口；匹配矩阵改为按产品分组卡片。
- Level 3 在窄屏使用全屏详情；不得让证据内容与编辑器并排挤压。

## 5. 视觉语言约束

- 中性浅色工作面、克制边框、单一主操作强调色；状态色只做辅助。
- 使用明确排版层级、状态标签、来源类别和时间，建立可信感。
- 不使用大面积渐变、过度玻璃拟态、无业务意义图表或聊天式主界面。
- AI 的存在体现在提取、匹配、证据链和行动建议，不增加独立“AI 表演区”。

## 6. 低保真交互检查点

1. 首次进入能否在 10 秒内理解当前客户需求和下一步。
2. 用户能否从 UNKNOWN 直接定位缺失资料和原始依据。
3. Action Panel 是否帮助行动而非重复中间内容。
4. 知乎不可用时是否仍有完整主路径。
5. 回复入口是否只在上下文充分时成为主 CTA。
