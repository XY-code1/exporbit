# TradePilot Inquiry Workspace UI 状态设计

> 状态：低保真交互状态规范  
> 原则：局部反馈、保留上下文、失败可恢复、外部来源故障不阻断主流程。

## 1. 状态层级

- **询盘生命周期：** `NEW / ANALYZING / NEEDS_INFORMATION / READY_TO_REPLY / COMPLETED / FAILED`。
- **信息可信度：** `CONFIRMED / INFERRED / NEEDS_CONFIRMATION / INSUFFICIENT_DATA / UNAVAILABLE`。
- **匹配判断：** `MATCH / MISMATCH / UNKNOWN`。
- **编辑状态：** 未保存、保存中、已保存、待复核、最终确认；与生命周期分开显示。

## 2. 十个必须探索的关键状态

### S-01 没有询盘
- **触发：** 首次使用或列表为空。
- **布局：** 左栏显示空列表；中间显示导入价值与四种格式；右栏隐藏。
- **主操作：** 新建询盘。
- **避免：** 虚构示例客户或空白仪表盘。

### S-02 导入询盘
- **触发：** 点击新建询盘。
- **布局：** 中间进入导入模式，展示方式切换、输入区、附件队列和原文预览。
- **反馈：** 每个附件独立进度；格式说明不包含未经验证的大小/页数/数量。
- **异常：** 文件级失败提供重试、替换、移除；成功项不被清空。
- **重复：** 显示疑似重复及关联记录；不自动删除/合并，用户确认后才合并。

### S-03 询盘解析中
- **生命周期：** `ANALYZING`。
- **布局：** Snapshot 使用局部骨架；原始询盘可读；右栏显示“正在提取需求”，不显示伪造下一步。
- **行为：** 用户可离开再返回；已有结果逐步出现，但未完成字段标记为加载中。
- **失败：** 核心解析失败且无结果才进入 `FAILED`；可重试或手工补录。

### S-04 Business Snapshot 已生成
- **布局：** 中间默认显示 Level 1；右栏显示一个下一步和待确认计数。
- **内容：** 需求、规格、数量、国家、匹配状态、缺口、下一步。
- **交互：** 点击字段看依据，点击缺口进入对应任务。
- **可信度：** 每项显示信息状态；数据不足不以默认值填充。

### S-05 产品匹配结果
- **布局：** 中间展示候选与六维矩阵；右栏显示 UNKNOWN 产生的待确认行动。
- **交互：** 接受、删除、添加候选，人工修正状态，确认主推/备选。
- **资料缺口：** 只显示当前询盘相关缺口；不自动修改产品资料；历史趋势为 P1。
- **空：** 无产品资料时提供补资料和暂不推荐路径。

### S-06 知乎研究中
- **布局：** 业务问题保持可见，知乎来源区局部加载；其他来源结果照常展示。
- **反馈：** 显示当前搜索问题和进度，不使用全屏 AI 动画。
- **行为：** 用户可修改问题或继续处理匹配/回复。

### S-07 知乎不可用
- **信息状态：** `UNAVAILABLE`，不等同无结果。
- **布局：** 知乎来源区显示不可用、重试和上次取得时间；海外与企业来源不受影响。
- **Action Panel：** 仅基于现有证据建议继续、补资料或核实。
- **禁止：** 伪造结果、清除历史证据或把整条询盘标为 `FAILED`。

### S-08 证据不足
- **信息状态：** `INSUFFICIENT_DATA` 或 `NEEDS_CONFIRMATION`。
- **布局：** 指明缺少什么、影响哪个结论，并给“补资料/手动搜索/向客户询问”入口。
- **行动：** 只能形成核实型建议，不生成确定性商业结论。
- **回复：** 使用询问或保留措辞。

### S-09 回复生成中
- **布局：** 编辑器保留当前正文，局部显示生成状态；目标、语言、语气和已选内容可见。
- **行为：** 新结果先作为候选，不覆盖人工正文；生成失败保留输入。
- **待确定：** 用户生成期间继续编辑时的冲突处理，在高保真前确认。

### S-10 回复已保存
- **编辑状态：** 已保存；询盘可进入 `READY_TO_REPLY`，最终确认后进入 `COMPLETED`。
- **布局：** 显示版本号、中文/英文、语气、作者和时间；历史版本入口持续可见。
- **最终确认：** 当前用户可确认和撤销；所有操作留痕；不触发发送。
- **恢复：** 历史版本复制到编辑区成为未保存草稿，再保存产生新版本。

## 3. 补充异常与空状态

| 场景 | 显示 | 可执行下一步 |
|---|---|---|
| 搜索无询盘 | 当前筛选和 0 结果 | 清除条件 |
| 文件无法解析 | 文件名、原因、保留成功项 | 重试/替换/移除/粘贴文本 |
| 客户主体不明确 | 候选主体与区分线索 | 选择/补线索/保留未确认 |
| 无匹配产品 | 缺少匹配而非 0 分 | 手动添加/补资料/暂不推荐 |
| 海外来源失败 | 来源级不可用 | 重试/使用其他证据 |
| 建议生成失败 | 保留证据与人工内容 | 重试/手工添加行动 |
| 保存失败 | 未保存正文和错误原因 | 重试，不推进状态 |
| 最终确认撤销 | 操作时间和当前状态 | 继续编辑/再次确认 |

## 4. 状态反馈组件

- 生命周期标签：列表和当前询盘页头。
- 信息可信度标签：字段、洞察和证据旁。
- 匹配状态单元：矩阵和移动候选卡。
- 局部进度条/骨架：导入、解析、来源检索和回复生成。
- 行内错误与恢复动作：不以 Toast 作为唯一反馈。
- 持续保存栏：显示未保存、保存中、已保存时间和版本。
- 操作记录：人工修改、最终确认与撤销可查看。

## 5. 状态转换约束

1. 保存失败不推进生命周期。
2. 单一外部来源失败不触发 `FAILED`。
3. `COMPLETED` 只由当前用户最终确认产生；撤销回到 `READY_TO_REPLY`。
4. 上游字段变化只使关联内容待复核，不删除历史版本。
5. “已确认”不等于“已执行”，“回复已保存”不等于“已发送”。
6. 加载、错误和刷新均不得清空未保存输入。
